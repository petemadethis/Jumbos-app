# Jumbos Mockups & UX Flow

This document details the intended user experience and layout for the core screens of the Jumbos platform.

## 1. Landing Page
**Goal:** Clearly communicate the value proposition and drive signups.
- **Hero Section:** Large heading "Find the right people in the right markets, fast."
- **Search Bar:** Centered call-to-action. "Enter a ZIP code to start networking."
- **Value Props:** Three-column layout highlighting:
  - **Location-First:** Network by market, not by noise.
  - **Deal Marketplace:** Real deals, real pros.
  - **Verified Professionals:** Only serious RE players.
- **CTA:** "Join the Network" (Emerald button).

## 2. Location-based Directory Search
**Goal:** Allow users to find professionals in specific markets via hierarchical selection.
- **Selection Flow:** State Selection > City Selection > ZIP Code Selection.
- **Results List:** Card-based layout.
  - Profile Photo
  - Name & Role
  - Primary Markets (ZIPs/Cities)
  - "Connect" or "Message" CTA.
*Visual: `assets/mockups/directory-search.png`*

## 3. Deal Marketplace Listing
**Goal:** Facilitate deal sharing and interaction.
- **Grid View:** 
  - Property Image (Thumbnail)
  - Title (e.g., "Off-market Triplex in 30303")
  - Price/Potential
  - Tag: "ZIP 30303"
  - Posted by: [User Name]
- **Detail View:**
  - Expanded gallery.
  - Full ROI metrics.
  - Market data.
  - Direct "Message Seller" button.
*Visuals: `assets/mockups/marketplace-search.png` (Grid) and `assets/mockups/deal-detail-view.png` (Detail)*

## 4. User Profile
**Goal:** Showcase a professional's expertise and active markets.
- **Header:** Cover photo (real estate themed) + Profile photo.
- **Bio:** Short professional bio.
- **Active Markets:** A list of ZIP codes/Cities the user covers.
- **Deals:** List of deals currently posted by the user.
- **Contact:** "Message" button.

## 5. Messaging Interface
**Goal:** Professional, direct communication.
- **Layout:** Standard two-pane view (Conversation list on left, Chat on right).
- **Context:** Top bar shows the user being messaged and their role.
- **Features:** Ability to attach deal links or property photos.

## 6. Signup/Login
**Goal:** Low friction.
- **Fields:** Email, Password.
- **Onboarding:** Ask for "Role" and "Primary Markets (ZIPs)" immediately after signup to populate the directory.
